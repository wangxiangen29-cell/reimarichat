总结 API 与自查 AI

自查 AI 使用你自己的 API，开启后每次输出前会多一次检查调用；总结可单独配置，也可以直接用内置。

不填 Key 时自动使用内置台词演示；填了 Key 就由 AI 实时对话。 Key 只保存在浏览器本地、只发给本地服务器，不会写进日志。 接口兼容 OpenAI 格式的服务（DeepSeek、通义等）也能用。

后台管理（服务器级开关）

这些是服务器级设置，需管理员口令才能改；口令见 config.json 的 adminToken 或启动日志。压缩强度档位越高，攒的对话越多才触发压缩、总结越详细（最低档才是 120 字提要）。

「一设」是东方官方设定的参考资料，可自行修改（仅本机生效）；自动闲聊使用的一设由管理员在 config.json 中管理。服务器开关与自动闲聊人设也在 config.json 中直接修改，保存后自动生效。

人设管理

人设 = 基础设定 + 补充设定 + 系统提示词（自动组合）。基础设定与系统提示词不建议修改，补充设定自由发挥；只存在你自己的浏览器里。

红白与黑白 · 使用说明

欢迎来到「红白与黑白」茶话会。这是一个让博丽灵梦和雾雨魔理沙用 AI 互相对话的同人小站，目前提供两种玩法。

功能介绍

  • 手动对谈：设定一个话题（比如「今天的异变」「蘑菇收成」），两位主角轮流接话；台词逐句点击推进，对话中随时可以插一句旁白推进剧情，结束后点「继续对话」还能接着聊。
  • 自动闲聊：管理员开启后，两人会在独立界面里不停闲聊；观众可以提议话题并投票，票数攒够就换题，没人提议时系统也会随机换题。
  • 油库里语音：每句台词可配「ゆっくり」风格语音（服务器代理，页面里直接开启即可）。
  • 人设管理：手动对谈的人设人人都能改（只存在你自己的浏览器里），分为基础设定、补充设定和自动组合的系统提示词。
  • 一设数据库：内置东方官方设定参考（整理自 THBWiki），帮助 AI 不崩人设；内容可以自己修改，仅本机生效。
  • 自查 AI（防 OOC）：填上自己的 API 后，每次输出前会多一次检查，台词不符合人设或一设时会自动润色；不配置就不启用。
  • 自动总结：对话积累到一定条数后，会自动把旧内容压缩成「前情提要」，既省 token 又能保持上下文连贯。
  • 演示模式：不接任何 API 也能玩，用内置台词演出，开箱即用。

关于内置 API（请务必看）

网站默认使用服务器内置 API Key 驱动 AI，由服务器代为调用、不会下发到浏览器。内置 token 是有限的——如果哪天 AI 不回复或报「调用失败」，可能就是这个原因。如果你有能力，建议在「设置 → AI」里填上自己的 API Key（兼容 OpenAI 格式的服务都可以），填了之后会优先使用你自己的 Key；Key 只保存在你的浏览器本地，不会写进日志或外传。
