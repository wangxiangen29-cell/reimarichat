红白与黑白 · 使用说明

欢迎来到「红白与黑白」茶话会。这是一个让博丽灵梦和雾雨魔理沙用 AI 互相对话的同人小站，目前提供两种玩法。

功能介绍

  • 手动对谈：设定一个话题（比如「今天的异变」「蘑菇收成」），两位主角轮流接话；对话中随时可以插一句旁白推进剧情，结束后点「继续对话」还能接着聊。
  • 自动闲聊：管理员开启后，两人会在独立界面里不停闲聊；观众可以提议话题并投票，票数攒够就换题，没人提议时系统也会随机换题。
  • 人设管理：手动对谈的人设人人都能改（只存在你自己的浏览器里），分为基础设定、补充设定和自动组合的系统提示词，默认是为主角组 CP 向打磨过的预设。
  • 一设数据库：内置东方官方设定参考（整理自 THBWiki），包括两人的一设、幻想乡世界观、主角组关系和 AI 易错提醒，帮助 AI 不崩人设；内容可以自己修改，仅本机生效。
  • 自查 AI（防 OOC）：在「设置」里填上自己的 API 后，每次输出前会多一次检查，台词不符合人设或一设时会自动润色；不配置就不启用。
  • 自动总结：对话积累到一定条数后，会自动把旧内容压缩成「前情提要」，既省 token 又能保持上下文连贯。
  • 演示模式：不接任何 API 也能玩，用内置台词演出，开箱即用。

关于内置 API（请务必看）

网站默认使用作者自己的 DeepSeek API Key 驱动 AI，由服务器代为调用、不会下发到浏览器。但作者的 token 是有限的，跑完就没有了——如果哪天 AI 不回复或报「调用失败」，可能就是这个原因，请多包涵。

因此，如果你有能力，建议在页面「⚙ 设置」里填上自己的 API Key（兼容 OpenAI 格式的服务都可以，比如 DeepSeek、通义等），填了之后会优先使用你自己的 Key。Key 只保存在你的浏览器本地、只发给本地服务器，不会写进日志，也不会外传。

自查 AI 和总结 API 也都可以在设置里单独配置自己的 Key，自查 AI 默认不使用内置 API。

后台管理说明

服务器级开关（内置 AI、自动闲聊、自动闲聊人设、一设默认值等）由管理员在 config.json 里直接修改，保存后自动生效，前端不提供管理界面。如果你看到自动闲聊未开启，说明管理员还没有打开它。
